# Security policy

Contraband runs with root privileges, so security reports are handled first.

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/knight-byte/contraband/security/advisories/new).
Do not open public issues for security problems.

You will get an acknowledgement within 3 working days. Fixes are released as
soon as they are ready, and reporters are credited unless they ask otherwise.
